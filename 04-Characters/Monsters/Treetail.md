# Treetail

*Bushtail's evolution. Claude-made (Round 54) at the designer's request. Final form (2-form family).*

| Field | Value |
|---|---|
| Animal | squirrel (evolved) |
| Home biome | Forest (same as Bushtail) |
| Spawn chance | **None.** Only obtained by evolving (Round 52 rule). |
| Size | Medium (2x Dumble) |
| How it moves | Leaps between spots; leaves rustle. |
| Look | A big squirrel whose **tail looks like a leafy tree branch**, with acorns hanging from it. |
| Ability (1) | **Quick**: always attacks first. *(same as Bushtail)* |
| Evolves into | Nothing, **final form** |
| Evolves at level X | n/a |
| Evolves from | [Bushtail](Bushtail.md) at **level 18** |

## Moves (max 4)
| # | Move | What it does | Power |

## Evolution note
When Bushtail evolves, **Acorn Toss is replaced by Pinecone Blast** automatically.
