# Controls (keyboard first, mouse also works)

| Action | Keyboard | Mouse |
|---|---|---|
| Move | Arrow keys or WASD | — |
| Talk / interact / confirm | Space or Enter | Click |
| Back / cancel | Esc or Backspace | Right-click or the Back button |
| Menu (Team, Backpack, Monster Book, Map) | M | Menu button |
| Battle: pick a move or option | Arrows + Enter, or 1–4 | Click |
| Battle speed-up | F (toggle) | Speed button |
| Skip text | Space (finish the line), Space again (next) | Click |
| Throw cage (if timing is chosen) | Space when the circle is small | Click |

No fast reactions or button-mashing are ever required. Rebinding keys is not in v1.
