# UI and HUD

Rules: big buttons, short words, icons next to text, nothing that relies on color alone, all text skippable.

## Title
New Game, Continue, Settings (music and sound volume, text speed, next-goal arrow on/off), Export/Import save.

## Exploring (HUD)
- Top left: area name (e.g., "Ansonville", "Beach").
- Top right: Magic Gems and cages count.
- Next-goal arrow and a one-line goal ("Catch your first monster!"), which can be turned off.
- Menu button (M): Team, Backpack, Monster Book, Map, Settings, Save.

## Battle
- Wild or enemy monster top right; yours bottom left. Name, level, HP bar (with a number), a Big star, status icons (🔥 Burned, 🧊 Frozen).
- Bottom menu: **Fight** (4 moves with power and element-tag icons), **Cage**, **Bag**, **Switch**, **Run**.
- One-line battle text; speed-up button.

## Catch
The tiny cage flies, grows big, closes, wobbles 1–3 times, then: "Gotcha!" or "It broke free!"

## Team (6) and Backpack (unlimited)
Two columns; select a monster, then select a slot to swap. Sort the Backpack by name, level, or biome.

## Monster Book
A grid of every monster: silhouette if not seen, picture if seen, ✓ if caught, ⭐ if caught Big.
Counter for the Avatar gate: "Wild monsters caught: X / 15".

## Shop
List with icon, name, price, and how many you have. Buy with confirm.

## Map and teleport (level 50+)
World map with Ansonville in the middle; locked biomes greyed out with a lock. Teleport list of shops and pins (place, delete).
